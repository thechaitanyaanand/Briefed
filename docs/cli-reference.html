03. CLI COMMANDS

Briefed is a single briefed binary with zero runtime dependencies (Node 18.3+ standard library only). Run briefed <command> --help for any command.

⚙️ Subcommands Directory

1. briefed init

Installs the post-merge, post-rewrite and post-checkout hooks (into .husky/ if present, otherwise .git/hooks/) and links .briefed/context.md from your agent files. Re-run it after upgrading Briefed: hooks written by an older version are upgraded in place, and your own hook code is left untouched.

# Standard initialization (or: npx briefed-cli init)
briefed init

# Interactive wizard: target, backend, API key
briefed init -i

2. briefed run

Summarizes what changed since ORIG_HEAD (falling back to HEAD~1) and prepends an entry to the target file. The hooks run this in the background, so git never waits.

briefed run [options]

Options:

  • -b, --backend <backend>: override the backend (gemini, anthropic, ollama, none).
  • -m, --model <model>: override the model.
  • -t, --target <path>: override the target file.
  • --since <ref>: diff from merge-base(<ref>, HEAD) instead of ORIG_HEAD (used by the branch-switch hook).
  • -v, --verbose: print diff stats, the backend used and the elapsed time.

3. briefed status

Shows the last run and the latest entry:

Last run:    2026-10-20T14:18:36Z (gemini, 1840 ms)
Target File: /work/app/.briefed/context.md
Date:        2026-10-20T14:18:36Z
Commit:      614df77…
Branch:      feature/auth

Summary:
- Auth moved from src/auth to src/security; import from there
- New `npm run db:migrate` script; run it after pulling

4. briefed context

Prints the recent-changes entries to stdout. Wire it to an agent's session-start hook and the agent gets the latest context without reading any file.

5. briefed stats

Local run statistics: entries and words in the context file, the number of runs, LLM vs commit-log summaries (including fallbacks after an LLM error), and the average run time. Stored in .git/briefed-stats.jsonl; nothing is sent anywhere.

6. briefed config

Prints the resolved configuration (defaults ← ~/.briefed.json ← .briefed.json ← environment) as JSON.

🔒 API key masking protection

Any resolved apiKey is printed as [REDACTED], so the output is safe to paste into issues or CI logs.

7. briefed uninstall

Removes Briefed's hooks from .husky/ and .git/hooks/. Standalone hooks are deleted; when Briefed was chained into one of your hooks, only its block is cut out.
